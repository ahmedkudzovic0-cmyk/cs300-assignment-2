## About this page

River Workshop is a fictional community workshop landing page built for CS300 Assignment 2.
It leads a phone visitor to the practice session cards with one primary action, "Explore the sessions".
The layout is mobile-first: a stacked single-column phone layout, then two min-width media queries at
640px and 960px add a horizontal navigation bar, a two- then three-column card grid, and a
side-by-side About section.
